# Mac本地独立补读

本包不含采集器、解密器、私有密钥或聊天库。先按[运行接入](../digital-employee/references/runtime-integration.md)发现实际只读工具及授权范围，再按[共同来源选择](../digital-employee/references/wechat.md)判断是否需要本机独立补读；参考部署主源仍为AUP。

## 读取

读取前核支持的来源、账号和文件元数据；按实际工具的有界时间窗、分页和输出合同执行，不照抄原作者路径或密钥配置。使用明确时区和左闭右开范围，保存新的私有导出及相邻收据，原库只读，不覆盖旧证据。

核账号、源库、时间窗口、逐源成功/失败、稳定ID、真实发送人、缺口、截断及实际最晚消息。派生库可能落后，读取截止、库最新消息、正文已读位和应用刷新时间不混用。晚导入旧消息单独核，不仅按消息时间过滤后断言不存在。

按完整讨论读取，关键词只定位。附件要实际取得，原消息定位、媒体身份与大小可关联；标题、缩略图和占位不等于内件已读。语音按真实会话和非零稳定ID定位原音频，转写不等于人工核听，不按近似时间拼配。

## 边界

只取本轮必要来源，私有原文、XML、媒体访问属性和密钥不公开。有限临时副本、超时与清理由实际工具保证；不为一次补读复制全库、重建采集器、轮换密钥或改系统权限。明确失败与未读范围留回原任务。

此Skill仅提供来源。调用员工负责理解、事项匹配与交付；需要发送走[wechat-write](../wechat-write/SKILL.md)，组织记录走[notebook-secretary](../notebook-secretary/SKILL.md)，不能把一次导出/ASR成功当所有业务已闭环。
