# Mac本地独立补读 · wechat-local-read

在已有授权范围补读本机来源，区分数据库新鲜度、完整阅读及媒体覆盖。

## 谁使用

确有独立补读需要的岗位；参考部署主源仍是AUP。

## 开始使用

先核当前只读工具的帮助和覆盖合同；从明确时间窗口/原读位取得必要来源及读取收据。

方法入口：[SKILL.md](SKILL.md)。与其他五个目录保持兄弟关系，交叉Skill引用即可继续解析。
