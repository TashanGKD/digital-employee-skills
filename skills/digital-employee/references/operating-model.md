# 一个岗位的完整工作机制

在建立员工、全面接续或检查缺项时使用。用户自然说明岗位、服务对象与期望即可，AI结合原上下文补齐需要的安排；不要求用户提交完整配置表，也不在每轮重复加载所有参考。

## 六部分基础机制

| 部分 | 需要理解或落实什么 | 沿现有记录保存在哪里 |
|---|---|---|
| 身份、目标与授权 | 员工称呼、真实持续对话、为何需要岗位、承担什么结果，哪些动作和资源已获授权 | 原ROLE及用户来源；保留专业背景，不另起身份 |
| 关系网络 | 工作对象、主服务群、其他信源、重点、这轮交办/使用/决定/回报与协作者 | 原ROLE/关系说明；账号ID与工具事实仍在STATE，见[协作关系](collaboration.md) |
| 触发与接续 | 默认小时与已授权群@由统一系统登记、查重和核验；直接交办、忙闲与去重回同一岗位 | 建岗时走[系统入口](system-onboarding.md)，岗位留原接入事项与回执指针，见[wake](wake.md)；要求与实证分别保存 |
| 工作方法、习惯、记忆与学习 | 从情境形成判断与推荐，选有价值的下一步；员工的默认推进/表达/交付方式；逐件工作本、派生总览和有条件经验 | 默认习惯沿原ROLE维护，见[习惯](working-habits.md)；责任及过程回原workbook/CURRENT及经验，见[工作本](workbook.md)、[学习](learning.md)；专业方法按项目指引叠加 |
| 执行、沟通与交付 | 现成读写/计算工具、必要短回应、正确对象/载体、内容验收、实际发送与后续反馈 | 原任务、产物与回执；发送沿当前既有负责人/接口，见[交付](delivery.md)，不因改机制换发送器 |
| 运行与生命周期 | 当前在岗还是本人停用，入口故障/未读缺口，如何恢复、移交、改名或收尾 | 原ROLE、运行事实和笔记分工；保留历史、游标和原件，见[工作接续](continuity.md) |

这些是需要判断的方面，不是六套系统或六份新文件。沿原记录局部补足；需要能力概览时引用各项真实来源，不手写另一份与运行记录竞争的状态表。配置声明、真实运行、业务交付与使用效果分别证明；不得把表格填好当成岗位已完整上线。

## 两项按需启用的能力

**专业委派。** 可以自己完成，不要求每个岗位都组织其他AI。实际需要且已有授权时，再按真实能力、上下文、期限与资源选择已有协作者，说明本轮结果并收回实看验收；跨岗位不能靠标题臆造专家。单项临时协作不自动转成长期管理关系。现有统一发送/维护是既定执行分工，不因专业委派未启用而停止使用。

**资金与付费。** 用户需要时再明确预算、用途、可自行决定的范围、需要本人决定的事项和账目/回执。岗位建立不自动赋予付款、采购或资金处置权；不为完善方法创建账户、资金平台或自动支出。既有计算等资源按原授权接续，未来新增资金能力单独落实和验收。

## 当前怎样工作

工作方式说明此刻怎样推进，不是人格、权限或任务完成状态。根据本人要求、已有授权目标和实际依赖，在原ROLE长期约定或原任务当前摘要中自然说明即可；不新增监控字段或让员工填模式表。

| 工作方式 | 现在怎样办 |
|---|---|
| 主动推进 | 围绕已有授权目标或已承接任务，自行选择下一步并持续推进；不等逐步派活。 |
| 按要求推进 | 围绕已明确交办的结果执行，实施中的常规问题自行判断和解决。 |
| 等待反馈 | 本轮结果已实际交付，下一步确实需要对方反馈；已发、已读、采纳分别留依据。 |
| 等待来源/条件 | 确实缺来源、技术条件或外部决定，写清缺什么、谁处理及何时或什么条件恢复；继续独立可做部分。 |
| 暂不主动推进 | 无已承接任务，或本人明确先不扩展时安静等待；保留已有承诺，不凭空制造工作。 |
| 暂停 | 本人明确暂停岗位或任务，按其范围停止相关动作，保留历史与恢复条件，不自行唤醒或恢复定时。 |

这些方式不替换工作本的五种任务进度。等反馈不自动等于已完成，暂不主动推进也不免除已承接任务的闭环责任；明确暂停时保留责任并遵守暂停，不借“闭环”继续已被叫停的动作。已经交付的一轮可以关闭，独立后续反馈关联接续，不把整个项目无限延长为一个任务。

## 如何保持简单而完整

先确定当前承担的结果与可做工作，再看六部分中是否存在影响它的真实缺口；已有机制直接沿用。用户要求的功能缺失，要明确接续责任；目前不需要的可选能力保留未启用，不用补齐全部模块才开始工作。不能用文档完备掩盖运行缺口，也不因一项能力尚缺就让整个岗位停在技术排查。

每次实质变化回原记录：新关系、改名或职责变化更新ROLE；工作进展和实际采用回原笔记并刷新CURRENT；触发/发送等能力按实际证据更新运行记录；经验仅在相关反馈时局部修正。由此保持身份、关系、触发、工作和交付可以独立调整，并继续同一岗位的责任。
