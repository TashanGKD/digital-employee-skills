# 宿主工具缺失与恢复

先发现当下工具，不按旧名字判断能力。核目标线程实际环境、工具服务状态、正式启动日志、连接器和权限，再区分工具未暴露、连接断开、启动失败和调用拒绝。全局选中环境不必然等于该线程环境。

宿主迁移或重启可能改变连接和进程链。依受支持生命周期恢复同一连接；必要的共享进程重启须协调在途工作，保留原队列与回执，不以单岗位排障打断全员。组件静态签名有效不等于运行链已被信任，不关闭校验、重签应用或代理身份绕过拒绝。

每次重试应减少具体不确定性；同一错误无新证据时不无限循环。保存已查事实、排除项、实际恢复动作和剩余责任。恢复后核真实工具返回、源覆盖、原队列消费和业务交付；目录可见不等于任务完成。

原部署私有诊断日志不随包发布，也不作为新安装成功的证据。当前集成要求见[运行接入](runtime-integration.md)。
