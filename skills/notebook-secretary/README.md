# 组织共同记事本维护 · notebook-secretary

从授权信源增量维护共同事项、进展及已发生的工作事实，保来源、批注与历史。

## 谁使用

指定的记事本维护员工；自己的工作本与组织主库分开。

## 开始使用

先读原入口、主库合同和上轮收据；核完整增量、旧项与实际新结果，保存后独立读回，再提交真实应用终点。

方法入口：[SKILL.md](SKILL.md)。与其他五个目录保持兄弟关系，交叉Skill引用即可继续解析。

## 随包内容

来源与判断参考、无个人资料的背景模板、数字回环隔离客户端和客户端测试。

## 实际依赖

真实共同记事本后端及其正式SDK由部署方提供；随包脚本不是云主库客户端。

共同接入说明：[运行环境接入](../digital-employee/references/runtime-integration.md)。不继承原作者账号或授权；安装Skill不等于工具已连通，文件检查不等于真实业务验收。

## 验证与关系

从[仓库README](../../README.md)运行适用的本地检查。默认不发微信、不创建调度、不改主库；实际操作由当前授权、原请求与真实工具能力共同确定。

开源适配基于2026-11-20方法快照，移除组织私有绑定和案例；原安装未被本发行修改。版本及边界见[发布说明](../../docs/RELEASE.md)。
