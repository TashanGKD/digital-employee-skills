# 来源、覆盖与检查点

先核用户授权、真实来源目录与原读位，再选择有界窗口。微信主源遵循[digital-employee来源规范](../../digital-employee/references/wechat.md)，使用[wechat-aup-control](../../wechat-aup-control/SKILL.md)；必要Mac独立补读用[wechat-local-read](../../wechat-local-read/SKILL.md)。飞书聊天/会议、邮箱和其他会议工具由宿主自行接入，不因安装本包获得这些权限。

每源分开保存账号、真实会话、时间范围、稳定原生ID、发送人、消息时刻及精度、工具来源、分页、覆盖缺口、媒体欠读和四个终点：取得、正文阅读、媒体阅读、应用主库。时间过滤不是永久水位，晚导入和后到旧消息须有界补核并去重。

不同来源同一原事项合并理解；同一会话连续补充不逐条建任务。未读数不是欠回数量，关键词搜索不是读完整讨论。卡片、标题、ASR和字节下载分别说明，不能冒充亲读完整内容。

Codex对话仅取授权的用户指令、可见答复、实际工具与交付证据；不读取内部隐藏推理。新旧线程新增回合按实际分页恢复，仍在运行的回合留待后续，不伪造精确时间。

保存成功前缀后再提交本轮应用终点。失败保上一轮指针和原欠账，单源故障不覆盖其余成功。原生来源、私聊、密钥和媒体不上公共仓库；组织主库只保必要事实摘要和准确无凭据定位。
