# 记事本服务接入与隔离客户端

本包不分发完整记事本后端、生产地址、设备配置、账号或私有数据。接入已有主库时先核它的真实合同、身份、版本、字段校验、冲突处理、幂等请求与读取终点；不能把示例loopback服务当你的生产主库，也不能因远端故障回写一套旧本地库。

## 随包提供的客户端

scripts/notebook_api.py只支持形如http://127.0.0.1:PORT的数字回环HTTP原点。无参数只显示帮助；create/record/append默认离线preview，只有显式--apply才接触写接口。它拒绝远端/歧义origin、重定向、代理、重复JSON键、非有限数值、超限内容及伪装人类确认。测试使用隔离临时服务，不连接你的主库。

这个客户端针对历史4.local隔离合同：health、bootstrap、messages、sources、jobs以及按ID的detail读取；create/record/append写入。其真实路径、字段及限制直接见脚本。它不支持HTTPS生产服务、完整云端主库或主库的全部能力，不能拿它报告云端集成已通过。

## 正式主库适配

使用该主库自己的受支持SDK和实际schema。写前验证字段、真实对象ID和当前revision；写时稳定requestId；写后独立读回受影响字段、原历史与来源。冲突先重新读用户新输入，未知先核原单，不盲重建或只提高版本。

原始聊天、完整逐字稿、媒体、XML和凭据留私有来源。线上仅存有必要且已获授权的摘要与可追溯定位；不伪造时间、ID或内容哈希。AI保存建议和事实，不冒充本人确认或将needsReview改为人类已阅。

来源取得、内容阅读和主库应用终点分开；只有保存读回后推进应用检查点。日周月汇总使用同一业务事实，不因报告产生重复工作记录。
