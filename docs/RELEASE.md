# 公开发行范围 · 2026-11-20

本仓库基于六个实际维护Skill的当前快照整理，采用MIT协议，面向可理解、可移植的使用和后续维护。上游文件输入哈希见UPSTREAM.json；这是溯源信息，不是公共文件校验值。公开载荷以根MANIFEST.json为准。

## 保留

共同工作方法与表达、专业适配、承接后结果责任、六种工作方式与五种任务进度、工作本模板/汇总、学习、交付、协作与验收原则。提供可复用脚本及隔离测试、三张架构图的SVG和云端导出预览，每个Skill都有独立README。

## 公开适配

- 移除固定账号、群、线程、联系人、私有路径、设备配置、运行日志和原业务案例；部署背景改为无个人资料模板，例子明确为合成情境。
- 把原绝对路径改为仓库/兄弟Skill引用；当前环境入口改为实际部署接线说明。
- 微信三个Skill保留方法，不把私有SDK文档或微信实现错误包装成随包组件。
- 队列整理库不再连接原私有socket，改由调用方注入已验证的适配器，并检查安全ID、独占归档目录及未知结果不重放。
- 记事本保留隔离回环客户端与独立客户端测试；原完整后端集成测试因依赖未随包提供的应用而未收入公开测试，不计为通过。
- 方法检查器保留原状态/来源/文件校验；跨Skill依赖由公开仓库检查器统一检查。独立安装或裁剪需重新核引用。

原作者的实际安装、服务、调度和业务没有被本公开包改动。本发行不承诺原Skill哈希完全相同，而是公开适配版。

## 验证范围

本地检查验证文件清单、自覆盖哈希、可识别的敏感模式、本地链接、Skill名称和必要README；负例检查防止只看正常包就说防线成立。它是有界模式检查，不是对所有隐私/机密形式的通用证明，发布者还需审阅实际内容。

方法测试验证文档/状态/打包边界；队列测试仅mock适配器；记事本客户端测试仅临时回环服务。不证明真实群可读、原生@触发、消息已送达、人工已读、业务采纳或所有员工长期正确。真实部署需按运行接入逐层验证。

## 版本维护

修改代码或文档后，先测试和审阅，再重新生成已审公开文件的哈希清单。MANIFEST不包含自身；其余公开检查器、同名self-test、测试、CI与hook都在清单内。不能通过自动重新封存来掩盖未审改动；提交时hook与CI复核同一载荷。
